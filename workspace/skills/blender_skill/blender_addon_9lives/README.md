# 9Lives Blender Live Addon

This folder is a self-contained Blender addon.

## Install

1. In Blender open `Edit > Preferences > Add-ons > Install...`
2. Select `dist/blender_addon_9lives.zip` generated by `package_addon.py`
3. Enable `9Lives Live Bridge`
4. Open the `9Lives` tab in the 3D View sidebar
5. Set host, port, token, and optional workspace root
6. Start the bridge

## Endpoints

- `GET /health`
- `GET /scene`
- `POST /execute`

All mutating work is dispatched on the Blender main thread via `bpy.app.timers`.
