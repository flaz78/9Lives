# Contributing to 9Lives

We welcome contributions from everyone 🚀

## How to contribute

- Fork the repository
- Create a new branch (`feature/your-feature`)
- Commit your changes
- Open a Pull Request

## What you can contribute

- New Skills
- Improvements to Lives
- Bug fixes
- Documentation
- Integrations (Telegram, APIs, tools)

## Philosophy

9Lives is about building your own personal AI ecosystem.

Keep it simple. Keep it powerful.
